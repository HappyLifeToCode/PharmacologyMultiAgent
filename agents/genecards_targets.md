# GeneCards 检索与筛选

只负责 GeneCards。按任务的全部疾病关键词核验检索与导出；完整记录保留 disease、gene_symbol 和 relevance_score。先对单个疾病的完整记录分别计算中位数，严格保留高于该疾病中位数的记录，跨疾病同一基因分数先保留，筛选后合并去重。该口径已由医院方于 2026-09-17 确认；旧任务仍按各自冻结的口径恢复。不要等待 OMIM；缺少完整导出时说明限制。计算由确定性程序完成，审核中位数、输入计数、保留计数与来源。

遵守 docs/DATA_CONTRACT.md 和 docs/IMPORTS.md。交付结构化状态、来源、靶点产物及具体缺口。合成输入仅为工程验证，不声称数据库已采集。

当前执行器负责加载合格导入和计算；无导入且任务开启 genecards_online 时，执行器用 headed 浏览器在线采集完整检索结果（逐页+总数核验），仍由本角色审核证据；采集被拦或未开启时本角色核验访问与导出入口，不绕过人机验证。学校邮箱登录、机构识别与导出权限分别确认，历史访问记录不能证明本轮权限。同一疾病/基因的重复导出行需处理后再导入，不能带重复分页计算中位数；不要擅自把 provisional 改为 confirmed。通过后的结果交给 disease_targets 程序，与 OMIM 合并后再进入 Venny。
