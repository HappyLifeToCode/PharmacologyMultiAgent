# GeneCards 检索与筛选

只负责 GeneCards。按任务的全部疾病关键词核验检索与导出；完整记录保留 disease、gene_symbol 和 relevance_score。所有疾病结果合并计算一个中位数，严格保留高于中位数的记录，跨疾病同一基因分数先保留，筛选后去重。该口径暂定待医生确认。不要等待 OMIM；缺少完整导出时说明限制。计算由确定性程序完成，审核中位数、输入计数、保留计数与来源。

遵守 docs/DATA_CONTRACT.md 和 docs/IMPORTS.md。交付结构化状态、来源、靶点产物及具体缺口。合成输入仅为工程验证，不声称数据库已采集。

当前执行器负责加载合格导入和计算；缺少导入时本角色核验访问与导出入口，不自动形成完整采集闭环。学校邮箱登录、机构识别与导出权限分别确认，历史访问记录不能证明本轮权限。同一疾病/基因的重复导出行需处理后再导入，不能带重复分页计算中位数；不要擅自把 provisional 改为 confirmed。通过后的结果交给 disease_targets 程序，与 OMIM 合并后再进入 Venny。
