## 更新范围

结构、流程或产物变化时，同步更新上述专题文档。项目当前进度集中维护在 PROJECT_STATUS；专题说明只写与本主题有关的状态。每个完成声明应区分：代码存在、独立测试通过、端到端工程通过、真实数据验收通过。

网站观察必须写实际访问日期；文档整理日期不是重新访问日期。历史运行、原始导出及参考原文作为证据保留，不为统一新表述而回写。

## 公开与本地

公开说明使用相对项目路径和通用 `.venv` 启动方式。`AGENTS.md`、参考原文和私人笔记在本地维护并由 Git 忽略；账号、密钥和完整运行目录不放进公开文档。忽略规则不提供访问控制，也不能撤回已经上传的文件。
