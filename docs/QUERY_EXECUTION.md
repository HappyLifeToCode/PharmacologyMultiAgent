# 会话查询加速与进度

首页正反向查询、工作台顶部正向查询显示实际执行阶段、已处理分片或关联行数、已用时间。通过既有 `GET /api/agent/{direction}/request/{request_id}` 读取进度，不另起计算。首次提交与刷新恢复均可显示；初始记录尚未创建或短暂轮询失败不会取消计算。不估算总进度百分比或剩余时间。

进度区上方单独显示灰色用时，分隔线下展示当前阶段及实际数量。首次打开或刷新页面默认定位到最新消息；同一页面内每段会话分别记住阅读位置，切换到其他会话再返回时恢复。原本位于底部时继续跟随最新消息；手动向上阅读及归档异步加载时保留对应消息的位置。阅读位置只保存在当前页面内存，刷新后恢复默认底部。

进度由工作进程写入 `local/agent/jobs/<run_id>.progress.json`，与主任务状态及研究归档分开。`progress` 包括 `phase`、`label`、`updated_at`、`elapsed_seconds`，有实际计数时附 `current`、`total`、`unit`，可附 `detail`。终态以请求状态 `status` 为准，取消时可能保留最后一个处理阶段。阶段包括数据版本核对、BATMAN、Open Targets 分片读取/关联保存、Monarch、聚合或反向匹配、结果保存和缓存复用。原页签接续、关闭约 10 秒取消、主动重试先停止旧任务的规则保留。

## 本地完整结果缓存

HTTP 工作进程默认在 `local/agent/query-cache/` 保存成功结果；直接调用 `forward.query()`、`reverse.query()` 仍执行计算。缓存键包含方向、完整研究输入及参数、本地源文件实际 SHA-256、计算代码、相关配置与 `PHARM_*` 环境设置。输入文字不同、Top-K 不同均重新计算，不按相似名称猜测复用。核对源文件哈希有额外 I/O，因此首次查询不保证更快；它仍需完成全量原计算。

必需源文件缺失、校验失败、原归档文件变更或缺失、缓存损坏，均回退计算；partial、失败和半成品不缓存。计算前后核对数据版本，变化时不保存可复用项。原归档及数据不被覆盖。缓存最多保留 16 项且总量不超过 1 GiB，清理仅限派生缓存，不删除研究归档。可在启动服务前设置 PowerShell `$env:PHARM_AGENT_QUERY_CACHE='false'` 关闭读写缓存。

每次缓存命中仍创建新的运行编号和结果归档。结果增加 `execution.cache_hit=true`、`source_fingerprint`、`reused_from`、`computed_at`；`created_at` 是本次归档时间，`computed_at` 是原计算时间。界面明确显示复用及原运行。候选、排序、分值、覆盖率、逐条证据和 `scientific_complete=false` 保留。冷计算记录 `cache_hit=false`；无法生成缓存键时 `source_fingerprint=null`。

缓存命中的新归档保存 `result.json` 和原有 `herb_targets.json`（如有），不会复制来源产物。`source_status` 保留原始计算的数据版本和流式采集元数据，其时间和来源不伪装成本次重新采集；原运行的持久化结果与证据摘要校验通过才允许复用。丢失原运行后下一次查询会重算。缓存不可用不应将已完成的计算改成失败。

## Open Targets 本地筛选

按疾病或靶点采集时先在 PyArrow 批次中过滤 ID，再转成 Python 行对象；原白空字符处理、重复行、排序、关联字段和保存的证据不变。没有用旧的 known-only 精简疾病索引替代完整 Open Targets 数据，也不裁剪反向疾病靶点分母。

2026-10-15 本机测量：14 个分片、7,225,847 条记录，肺腺癌 ID 筛选匹配 10,763 条原始行；原 Python 方法 7.991 秒，Arrow 方法 0.699 秒，匹配行顺序及全部字段 SHA-256 一致。这只衡量筛选阶段；不代表所有查询都有相同加速倍数。验证证据保存在本机 `local/checks/query-speed-20261015/`。

同次真实 HTTP 肺腺癌查询首次完整计算 25.580 秒，重复查询命中缓存 6.103 秒（包含版本/原归档核对、接口响应及验证轮询开销）。两次均为 10,694 个疾病靶点、4,389 条候选药材；前五条候选的全部计算字段、证据、排名及覆盖率与旧归档一致。桌面 1440 与手机 390 宽度验证首次进度、短暂 404/网络失败后继续、缓存说明和刷新只读，无 JS 错误或页面横向溢出。原归档哈希不变，临时 8773 已关闭，未操作用户终端的生产服务。
