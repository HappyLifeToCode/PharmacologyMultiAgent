## 参考文献及评价边界

温经汤参考为 [PMID 16552830](https://pubmed.ncbi.nlm.nih.gov/16552830/)（2006）：54名此前未排卵患者分成两组各27名，属于特定人群的换方研究。半夏白术天麻汤参考为 [PMID 23320025](https://pubmed.ncbi.nlm.nih.gov/23320025/)（2012）：系统综述纳入16项试验，明确指出方法学质量较低、证据弱、安全性不确定，且包含加减方或合用降压药。

这两例仅表示文献研究过的方剂—疾病关系。具体组成、剂量、加减尚未与本项目逐味核对；文献可能已被关联库收录，不构成独立外部验证集。没有负例，不计算 precision、临床敏感度或治疗有效率；样本只有两例，不做显著性或普遍优劣结论。不能把其余候选直接判为错误。

## 开销与可复现性

历史半夏白术天麻汤冻结 CSV、Top-K=10、背景已准备的一轮顺序 A/B 聚合测量：

| 聚合阶段 | 58.401秒 | 58.781秒 |
| 候选/证据 JSON 序列化 | 0.409秒 | 0.485秒 |
| 候选/证据 JSON 部分 | 32,374,299字节 | 41,368,019字节 |

单列表程序仍计算背景指标，只不加载/发布另一列表的额外证据，主要隔离额外证据成本。排除了采集、版本核对、首次建背景、缓存保存、完整 HTTP 和浏览器；只有一次顺序测量，受文件缓存和 CPU 状态影响，不能把0.380秒视为普遍固定开销。JSON 部分约增加28%。这是旧 CSV 路径的历史测量，不能作为合并后流式路径的性能证明。

本次当前流式温经汤、半夏查询在背景已准备时分别记录41.18秒、30.82秒，包含额外验证读取开销，未作单/双列表受控计时，也不是 HTTP 端到端耗时。新流程保留 OT 分层独立参考，联合证据集合也与历史测量不同。两种主视图共用两遍来源扫描；切换已返回视图不发新研究请求。

单元检查打乱关联行后名次与校正分值不变；真实查询核对完整证据数量、known-only 输入、默认支持度、分层参考及未生成关联 CSV。工程可复现不等于科学有效。
