# 文献模块独立交付

## 2026-10-26 拒绝访问后的自动切换

新任务先使用无界面专用Edge。主文档导航（包括检索跳转及详情页）实际返回HTTP 403时，在同一任务、同一项目资料目录中自动正常切换一次到可见模式，继续读取已保存的进度。已切换的任务续跑沿用可见模式，新任务仍先后台。429限流、超时、登录或验证码不触发自动切换；有头模式仍拒绝或出现登录/验证码时暂停并保留可见页面，等待手动处理。不会改User-Agent或伪装浏览器，也不会自动处理验证码。

这次“一贯煎”实际复现了主页200→跳转302→检索403，Chromium将它替换成chrome-error内部页；旧程序只等DOM，因而误报search_results_unavailable。现在按主文档响应判断，忽略子资源/iframe错误，并区分403、429和检索超时。私有diagnostic仅记录主机/路径/状态码，不记录查询token、HTML或表单值。

任务状态公开browser_mode及browser_fallback，页面说明自动切换情况。切换必须由持有本进程采集锁的工作线程执行，手动打开接口仍拒绝打断活动采集。已保存论文和完整页码核对继续复用，全量要求、模型、标题摘要范围及文献排序不变。

本项目已拥有文献分析、数据校验/导入/打包、采集执行器、标题摘要关系抽取和提示模板。日常运行只读本项目`data/cnki`或显式配置的`PHARM_CNKI_DATA_DIR`，不再寻找同级UI-Agent，也不再使用`PHARM_CNKI_PROJECT_DIR`。

更新代码、导入数据并重启服务加载新版后，旧UI-Agent文件夹可以移走或自行删除，本项目的本地文献功能不受影响。Python、模型 API、浏览器等运行环境是独立的软件依赖，不属于旧工程源码。

## 题录清单与摘要分开续跑（2026-11-02，覆盖前述总数策略）

网页全量任务先只遍历题录，不读取摘要。中间页计数差异经同页复核后作为诊断保留，不单独停止；页码/题录变动、重复、缺页或验证仍停止。实际唯一题录条数必须等于首末页总数、且末页无下一页，才固定listing_inventory.json。若网站只开放部分分页，不能把这部分冒充全量。

固定后沿清单补采摘要并复用已有论文。摘要阶段中断，续跑不再从第一页重新读取实时检索数；清单损坏拒绝使用，不自动重建。失效URL只能经正常页面按唯一精确论文身份更新，不能换成其他论文。旧任务未固定清单时，第一次续跑仍要核验完整题录，但已有摘要不会删除。网页明确显示“核对全部题录清单”和“清单已固定，补采标题摘要”；runtime_version=20261102-frozen-listing，Python更新由用户原终端重启后生效。
