# 界面基础规范

更新：2026-11-04。适用：研究问答、数据库查询、研究工作台、CNKI 证据面板。

## 方向与来源

保留暖白底、砖红品牌色、草木绿研究操作的既有风格。使用 UI UX Pro Max 的医疗界面与可访问性建议，结合实际页面确定设计；其自动生成的作品集、营销首页结构不适用于本项目，未采用。

技能安装在开发者本机，不是网站运行依赖。团队以本文和 `server/static/theme.css` 为共享设计入口，无需安装技能即可运行项目。

## 已接入的基础样式

| 用途 | 统一值 |
|---|---|
| 页面背景 | `--ui-page: #f8f5ef` |
| 内容表面 | `--ui-surface: #fffcf7` |
| 正文 | `--ui-text: #342f2a` |
| 次要文字 | `--ui-muted: #6b6259` |
| 边界 | `--ui-line: #d9cfc2` |
| 品牌强调 | `--ui-brand: #9f4433` |
| 研究操作、键盘焦点 | `--ui-research: #315b4b` |
| 正文字体 | Segoe UI、Microsoft YaHei、系统无衬线回退 |

首页与工作台先加载 theme.css，再加载各自样式；工作台主要按钮、下载按钮、表单边界和面板已接入共享变量，CNKI 面板共享基础颜色与字体。页面保留各自的信息密度和业务布局。

## 交互约定

- 按钮需有名称；图标按钮保留可访问名称和键盘焦点。
- 复制按钮按用户要求悬停显示，同时支持键盘聚焦与触屏。
- 图谱视图用原生复选框切换，节点保留原句溯源，不能靠颜色表达全部含义。
- 新增组件优先使用共享变量；状态颜色保留业务语义，不将所有状态涂成同一色。
- 后续逐步迁移遗留硬编码颜色和字号。本轮仅统一基础层，未完成全站可访问性认证或全部组件改造。
